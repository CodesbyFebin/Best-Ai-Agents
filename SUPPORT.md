# Support

## Getting help

- **Documentation:** start with [`README.md`](README.md) and
  [`docs/architecture.md`](docs/architecture.md).
- **Methodology questions:** see [`/methodology`](https://bestaiagent.in/methodology).
- **Bugs & feature requests:** open an issue using the provided templates.
- **Security issues:** follow [SECURITY.md](SECURITY.md) — never公开 (publicly).

## Communication channels

| Need | Where |
| --- | --- |
| Usage question | GitHub Discussions (Q&A) or an issue |
| Report a bug | `bug_report` issue template |
| Suggest a feature | `feature_request` issue template |
| Correct catalog/evidence | `documentation` issue template |
| Private vulnerability | GitHub Security Advisories (see SECURITY.md) |

## What we do not support

- Custom agent-building or orchestration (this is a discovery directory, not an
  agent framework).
- Guarantees about third-party product behavior or pricing; we only surface
  verifiable, dated evidence.

## Response expectations

BestAIAgent.in is maintained on a best-effort basis. Issues are triaged using the
labels defined in [CONTRIBUTING.md](CONTRIBUTING.md).
